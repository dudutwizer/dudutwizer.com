My Productivity Stack

The software I actually pay for, how I use it, and a graveyard of the tools that didn’t survive contact with my workflow. I keep the stack small on purpose: fewer tools, each doing real work, most of them increasingly run by agents rather than by me.

Daily drivers

Dia Free
My main browser. I let agents drive it for research and for testing what I ship.
Raycast Free
Launcher and command bar. Basically everything starts with a keystroke here.
Superhuman Paid
Email, keyboard-first and fast. The only inbox I can stand.
Wispr Flow Paid
Voice dictation. I talk, it types - most of this site was written by voice (typos included).
Astropad Paid
I drive and control my Mac mini from my iPad with it.
AltTab Free
Proper Windows-style window switching on macOS.
Clocker Free
Tel Aviv and San Francisco clocks in the menu bar, for a two-timezone life.

AI & agents

xpander.ai Built it
Where I build, run, and manage every agent I use. I dogfood it every single day.
Claude Code Claude Max
My primary coding agent. It wrote most of this website while I directed.
Codex Paid
OpenAI's autonomous coding agent for the bigger, boring changes.
Plaud Paid
AI recorder and notetaker. I stopped taking notes by hand - this captures calls and ideas for me.
Hark Paid
Native iOS notifications from my agents - my phone buzzes when one needs me or finishes.
Model Usage Free
Menu-bar tracker so I can see what the models are actually costing me.

Build & infra

VS Code Free
My editor. Cursor was fun, but VS Code plus agents won.
GitHub Paid
Code, CI, and the source of truth for everything I ship (gh + Desktop).
CLI toolbelt Free
gh, awscli, kubectl, pnpm, node, psql, redis, hugo - and Fira Code as the font.
Supabase Paid
Postgres, auth, and storage behind the products.
Cloudflare Free
DNS, Workers, and the proxy that keeps my API keys off the client.
Tailscale + Mullvad Paid
Private mesh network into my machines, with Mullvad exit nodes for a fully private connection.

Comms & docs

Slack Paid
Team HQ. My agents live here too, as teammates.
Notion Paid
Docs, specs, and the company wiki.
Sublime Text Free
My scratchpad for temp notes. I don't keep a notes system anymore - just a fast throwaway buffer.
Bitwarden Free
Passwords and secrets, self-hostable and open source.
